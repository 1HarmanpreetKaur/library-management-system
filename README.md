# Library Management System

A full-stack Library Management System originally built as a group project 
for a 2nd year Data Structures course. I extended it individually by adding 
a REST API layer and deploying it as a live web application.

## Live Demo
https://library-management-system-d1a7.onrender.com

## Original Group Project
- Core data structures: Dynamic Array, Linked List, Queue
- Library logic: book management, member management, borrow/return system

## Tech Stack
- Java 17, Spring Boot 3.5
- Custom Data Structures (no libraries used)
- HTML, CSS, Vanilla JavaScript
- Docker, Render (deployment)

## Features
- Add, search, delete books
- Register and manage members  
- Borrow and return books with automatic waitlist
- Pre-loaded demo data on startup
